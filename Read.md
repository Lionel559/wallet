# Wallet Connect App

A simple Web3 wallet connection interface that allows users to connect their crypto wallets and interact with blockchain-based applications.

## Technologies Used
- HTML
- CSS
- JavaScript
- Web3.js
- WalletConnect

## Features
- Connect crypto wallet
- Display connected wallet address
- User-friendly interface
- Web3 integration
